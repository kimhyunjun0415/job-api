# 실시간 구인 불러오기 (job-api)

GitHub Pages에 호스팅된 차량 랩핑/PPF 채용 바로가기 페이지입니다.
백엔드나 API 연동 없이 동작하는 정적 페이지입니다.

## 사용 방법

`index.html`을 열면 탭 3개(미리보기 / 바로검색 / 홈에서 검색)와, 그 아래 검색어 선택
영역이 있습니다. 검색어를 바꾸면 세 탭 내용이 모두 같이 갱신됩니다.

1. **미리보기 (화면 안)**: 사람인·잡코리아를 화면 안 iframe으로 바로 보여줍니다. 잡코리아는
   좁은 화면에서 자체 반응형 레이아웃이 깨져서, iframe을 1100px 폭으로 띄운 뒤 화면 크기에
   맞게 축소(scale)해서 표시합니다. ⤢ 버튼으로 전체화면으로도 볼 수 있어요.
2. **바로검색 (새 탭)**: 알바몬/원티드는 검색어가 URL에 포함되어 새 탭에서 결과가 바로
   열립니다.
3. **홈에서 검색 (새 탭)**: 알바천국/인크루트/고용24/당근 알바는 검색어를 URL로 넘길
   방법이 없어서 사이트 자체에서 직접 검색해야 합니다. "복사" 버튼을 누르면 현재 검색어가
   클립보드에 복사되니, 새 탭에서 사이트를 연 뒤 검색창에 붙여넣으면 됩니다. (다른 도메인의
   iframe 안 검색창에 자바스크립트로 자동입력하는 건 브라우저 보안 정책상 불가능해서
   복사 방식으로 대신합니다.)

## 사이트 목록 수정

`index.html` 안의 `previewSites`(화면 안 미리보기) / `directSites`(바로검색, 새 탭) /
`homeSites`(홈에서 검색, 새 탭) 배열을 수정하면 됩니다. `urlTpl`에 `{kw}` 자리표시자를
넣으면 검색어가 URL 인코딩되어 치환됩니다. 어떤 사이트를 미리보기로 옮기기 전에는 실제
좁은 화면(또는 iframe)에서 레이아웃이 안 깨지는지 먼저 확인하는 게 안전합니다. 깨진다면
`previewSites` 항목에 `nativeWidth`/`nativeHeight`를 지정해 잡코리아처럼 넓게 띄운 뒤
축소해서 보여주는 방식을 쓸 수 있습니다.

## 배포

`main` 브랜치에 push하면 GitHub Pages가 자동으로 반영합니다 (저장소 Settings → Pages 참고).

## 신규 공고 알림 (ntfy)

`scripts/fetch-jobs.js`가 GitHub Actions(`.github/workflows/poll-jobs.yml`)에서
**한국시간 09:00~24:00 사이 30분마다** 사람인/잡코리아/알바몬/원티드를 훑어서, **새로 올라온
공고가 있을 때만** [ntfy](https://ntfy.sh) 토픽으로 알림을 보냅니다. 새 공고가 없으면 알림도
없고, 이미 본 공고(`data/seen.json`에 기록)는 다시 알리지 않습니다. Firebase나 커스텀 앱
없이, 이미 있는 ntfy 앱으로 폰 알림을 받는 방식입니다.

- 자정~오전 9시(KST)에는 스케줄 자체가 실행되지 않습니다. 시간대를 바꾸려면
  `.github/workflows/poll-jobs.yml`의 cron(`*/30 0-14 * * *`)을 수정하세요 — GitHub
  Actions의 cron은 UTC 기준이라 KST 09:00~24:00은 UTC 00:00~14:59에 해당합니다.
- Actions 탭에서 **Run workflow**로 수동 실행하면 이 시간 제한과 무관하게 즉시 실행됩니다
  (테스트용).
- 평소엔 사이트당 최대 10건까지만 보내서 알림이 한 번에 몰려오지 않게 막아뒀습니다. 밀린
  공고를 한 번에 정리하고 싶으면 Actions 탭 → **Run workflow** 눌렀을 때 나오는
  `max_per_site` 입력창에 큰 숫자(예: `999`)를 넣고 실행하세요. 그다음 예약 실행부터는
  다시 기본값 10으로 돌아갑니다.

설정 방법:

1. 폰에 **ntfy** 앱 설치 (Play 스토어 검색: `ntfy`)
2. 앱에서 "+"를 눌러 토픽 구독. 토픽 이름은 아무나 추측 못 하게 임의 문자열로 정하세요.
   (예: `wrapjob-lapping-9f3kq2x` — 실제로 쓸 토픽 이름은 본인만 알고 있어야 합니다.
   ntfy.sh는 공개 서버라 토픽 이름을 아는 사람은 누구나 구독/발행할 수 있어요.)
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret**
   - 이름: `NTFY_TOPIC`
   - 값: 2번에서 정한 토픽 이름 (저장소가 public이라 코드에는 절대 직접 적지 마세요)
4. Actions 탭 → "Poll job sites and send ntfy notifications" → **Run workflow**로
   수동 실행해서 폰에 테스트 알림이 오는지 확인하세요. 이후로는 위 시간대에 30분마다
   자동 실행됩니다.

### 매칭 · 중복 방지

링크 텍스트에 검색 키워드가 실제로 들어있는 것만 알림으로 보냅니다 (전에는 "채용/공고
같은 단어만 있어도 통과"하는 느슨한 기준이라 랩핑이랑 무관한 메뉴 링크까지 잡혔었어요).
같은 공고가 키워드마다, 실행 회차마다 붙는 추적 파라미터(`stext`, `listno`, `sc` 등)
때문에 중복 알림이 가는 것도 그 파라미터들을 제거한 URL을 기준으로 판단해서 막습니다.

### 한계

스크래핑은 실제 채용 API가 아니라 검색 결과 HTML의 링크를 휴리스틱으로 훑는 방식이라
사이트 구조가 바뀌면 새 공고를 못 찾거나 엉뚱한 링크를 잡을 수 있습니다. 안정성이 중요하면
사람인 API(액세스 키)가 있을 때 `scripts/fetch-jobs.js`를 API 호출로 바꾸는 걸 권장합니다.
