# 랩핑잡 (job-api)

GitHub Pages에 호스팅된 차량 랩핑/PPF 채용 바로가기 페이지입니다.
백엔드나 API 연동 없이 동작하는 정적 페이지로, 검색어를 고르면
각 구직 사이트의 검색 결과 페이지를 새 탭에서 열어줍니다.

## 사용 방법

1. `index.html`을 열면 검색어 프리셋(차량랩핑, PPF 등) 또는 직접 입력한 검색어로
   사이트 목록의 검색 URL이 갱신됩니다.
2. 사이트 카드를 누르면 새 탭에서 해당 사이트의 검색 결과(또는 홈)가 열립니다.
   - `바로검색` 배지: 검색어가 URL에 포함되어 결과 페이지가 바로 열림 (사람인/잡코리아/알바몬/원티드)
   - `홈` 배지: 사이트 구조상 검색어를 URL로 넘길 수 없어 홈에서 직접 검색해야 함 (알바천국/인크루트/고용24/당근 알바)

## 사이트 목록 수정

`index.html` 안의 `sites` 배열을 수정하면 됩니다. `urlTpl`에 `{kw}` 자리표시자를 넣으면
검색어가 URL 인코딩되어 치환됩니다.

## 배포

`main` 브랜치에 push하면 GitHub Pages가 자동으로 반영합니다 (저장소 Settings → Pages 참고).
